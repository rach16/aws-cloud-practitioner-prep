# Week 1: Cloud Concepts, Billing, Pricing and Support

Friday 6 to Thursday 12 November. Domains 1 (24%) and 4 (12%). Both are the
business and memorisation half of the exam. Front-loaded so they get four
weeks of nightly review instead of one.

Before each evening: 15 minutes of [service-catalogue.md](../notes/service-catalogue.md),
one category, then two sections of [exam-traps.md](../notes/exam-traps.md).

- [ ] **Fri 6** · Setup, 60 min
  - [ ] Read the [official exam guide](https://docs.aws.amazon.com/aws-certification/latest/examguides/cloud-practitioner-02.html) end to end, 20 min. Note anything in the in-scope list you cannot place.
  - [ ] Take the free Skill Builder official practice question set cold, 20 questions. Log the score in [practice/log.md](../practice/log.md) as the baseline.
  - [ ] Buy the Tutorials Dojo practice exam set, or confirm Skill Builder access. Do not open it yet.
- [ ] **Sat 7** · Cloud concepts, part one, 90 min
  - [ ] [notes/01](../notes/01-cloud-concepts.md) sections 1.1 and 1.2: six advantages, Well-Architected pillars, CAF perspectives.
  - [ ] Write the six pillars and six CAF perspectives from memory on paper. Repeat until correct.
  - [ ] Self-test questions 1 to 5.
- [ ] **Sun 8** · Cloud concepts, part two, and C1, 90 min
  - [ ] [notes/01](../notes/01-cloud-concepts.md) sections 1.3 and 1.4: 7 Rs, migration tools, cloud economics.
  - [ ] Project [C1 cost controls](../projects/c1-cost-controls), 45 min. Write up `results.md`.
  - [ ] Self-test questions 6 to 10.
- [ ] **Mon 9** · Pricing models, 60 min
  - [ ] [notes/04](../notes/04-billing-pricing-support.md) section 4.1: On-Demand, RIs, Savings Plans, Spot, Dedicated, data transfer, Free Tier.
  - [ ] [exam-traps.md](../notes/exam-traps.md): the pricing section, cover-and-recall.
- [ ] **Tue 10** · Billing tools and support plans, 60 min
  - [ ] [notes/04](../notes/04-billing-pricing-support.md) sections 4.2 and 4.3.
  - [ ] Write the five-plan support table from memory: response times per severity, TAM, Trusted Advisor scope. Repeat until correct. This is the single most memorisation-heavy table in the exam.
- [ ] **Wed 11** · C2, 60 to 75 min
  - [ ] Project [C2 pricing API](../projects/c2-pricing-api). Run it, read the output against what section 4.1 claimed, write up `results.md`.
  - [ ] Run the Spot price checkpoint and compare it with On-Demand for the same instance.
- [ ] **Thu 12** · Week review, 60 min, **short**
  - [ ] Self-tests for notes 01 and 04 again, all 20 questions, closed notes.
  - [ ] Support table and pillars from memory one more time.
  - [ ] Update [weak-spots.md](../practice/weak-spots.md) with anything missed twice.

**Done when:** both self-tests at 9 or better, support table and pillars
reproducible from memory, C1 and C2 written up.
